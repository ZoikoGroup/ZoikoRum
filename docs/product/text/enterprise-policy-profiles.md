## 2. WHAT IS A POLICY PROFILE

A Policy Profile is a pre-configured, enforceable rule set that governs:

- Who can be engaged

- Under what conditions

- With what approvals

- At what spend levels

- Under which jurisdictions

- With which payment protections

- With what audit outputs

If an engagement does not satisfy the profile, it cannot proceed.

## 3. POLICY PROFILE OBJECTIVES

Each profile must achieve:

- Clarity — Rules are visible and explainable

- Consistency — No ad-hoc overrides

- Authority — Decisions map to named roles

- Traceability — Every exception is logged

- Defensibility — Outputs withstand audit

## 4. POLICY PROFILE TYPES (DEFAULT LIBRARY)

### 4.1 Regulated Engagement Profile

- Trust Tier A only

- Credential validation mandatory

- Jurisdiction eligibility enforced

- Restrictions screening enabled

- Escrow mandatory

- Multi-approver release

### 4.2 Enterprise Standard Profile

- Trust Tier A or B

- Identity verification required

- Standard contract templates

- Escrow above threshold

- Single approver release

### 4.3 Cross-Border Engagement Profile

- Jurisdiction mapping enforced

- Regional contract variants

- Currency controls

- Enhanced compliance flags

- Legal review trigger (optional)

### 4.4 Growth & Advisory Profile

- Trust Tier B minimum

- Simplified contracts

- Optional escrow

- Lower approval thresholds

Profiles are templates, not limits. Enterprises may create custom profiles.
