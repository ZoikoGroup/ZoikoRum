## 1. EXECUTIVE INTENT

The Request Proposal & Engagement Flow is the moment of truth in Zoikorum.

This flow converts:

- discovery → intent

- intent → governed agreement

- agreement → protected transaction

The system must make high-stakes professional engagement feel safe, clear, and inevitable, without introducing friction or bureaucracy.

This flow must:

- Reduce buyer hesitation

- Prevent scope ambiguity

- Enforce governance before work begins

- Protect both parties symmetrically

- Scale from solo buyers to enterprise procurement

This is not a messaging form.
 This is not an informal inquiry.
 This is a contract-preparatory, payment-ready engagement flow.
